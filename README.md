# 网页视频下载器

适用于 Chrome、Microsoft Edge 和兼容 Manifest V3 的 Chromium 浏览器。播放网页视频后，点扩展图标选择要保存的视频。完整媒体交给浏览器下载，分离的音视频在浏览器内合并，成品进入浏览器默认下载目录和下载记录。

[下载安装包](https://github.com/KmBooy/web-video-downloader/releases/latest) · [报告问题或建议](https://github.com/KmBooy/web-video-downloader/issues/new/choose) · [贡献指南](CONTRIBUTING.md)

## 安装与更新

1. 在 [Releases](https://github.com/KmBooy/web-video-downloader/releases/latest) 的 **Assets** 下载 `web-video-downloader-v*.zip`，解压后把 `web-video-downloader` 文件夹放到一个长期保留的位置。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。开启开发者模式，点「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
3. 打开视频页并播放几秒。点扩展图标，再点列表中要保存的视频。最多可同时下载 4 个视频，切换页面后仍可添加新任务。弹窗只显示当前标签页和网页的任务，标题最多显示 30 个字符，状态在右侧。点「×」可取消对应任务。刷新网页会清空该页已结束的记录，进行中的任务继续。
4. X 和 Instagram 可在视频画面、遮罩或对应帖子区域右键，选「下载这个视频」。扩展按选中的视频匹配来源并加入下载；视频已切换或存在多个无法区分的候选时，会提示重新选择。X 上按住 Shift 右键可使用网站原菜单。
5. 更新时，把新包中的文件覆盖到已经加载的文件夹，再在扩展管理页点「重新加载」。从 **0.2.12 或更早版本**迁移时，先记下画质和大小上限，移除旧扩展，再加载新版一次。从 0.2.13 起使用固定 ID，后续更新会保留设置。

发布包通过 GitHub 分发，使用浏览器开发者模式手动安装。

## 支持范围

| 类型 | 当前实现 |
| --- | --- |
| 普通网页 | 识别 MP4、WebM 等完整文件，以及可处理的 HLS、DASH 点播流 |
| 抖音 | 普通视频优先保存完整文件。部分直播回放会合并分离的音视频 |
| B 站 | 按当前分 P 匹配并合并音视频 |
| X | 识别完整视频和 HLS，支持部分无声动图，也能保存 HLS 主清单明确只声明 AVC 视频轨的无声视频 |
| Instagram | 识别当前信息流可见视频、帖子和 Reels 的完整 MP4，下载时更新对应帖子的来源，支持视频轮播；画质以站点提供的完整文件为准 |
| 小红书 | 从可播放的当前笔记中识别视频 |
| YouTube | 实验性支持普通视频和 Shorts。Shorts 开始播放后识别，滑到下一条后重新匹配当前视频。部分视频或画质可能不可用 |

播放中的直播可被识别，带完整点播清单的回放可以尝试保存。持续直播录制、播放器录屏和 DRM 加密媒体超出当前范围。平台更新、登录状态、地区和 CDN 可能影响识别或保存。

## 下载设置与隐私

- 扩展设置可调整画质和单文件大小上限。下载目录跟随浏览器，浏览器也会保存下载记录。
- 下载请求沿用浏览器和系统的代理设置。Surge、Clash、V2Ray 等客户端通过系统代理或 TUN 接管网络时，仍由客户端的规则决定如何分流。
- 为识别不同网页及其媒体 CDN，扩展申请访问 HTTP 和 HTTPS 网站。扩展会在浏览器内处理媒体地址和播放信息，只有用户点击下载才会保存。部分站点请求会沿用浏览器现有的会话。YouTube 适配会短期使用当前播放器的播放凭据，凭据留在浏览器会话中，仅发给对应的 GoogleVideo 媒体服务。
- 扩展没有自己的下载服务器或分析服务。合并使用浏览器的私有临时存储，设置保存在浏览器内。

请保存你拥有或已获授权下载的内容，并遵守所在平台的使用条款。

## 遇到问题

| 情况 | 先试什么 |
| --- | --- |
| 没有识别到视频 | 确认网页能播放正片，再点「重新扫描」 |
| X 或 Instagram 识别到其他视频 | 在目标视频或对应帖子区域右键，选「下载这个视频」 |
| 地址过期或返回 403 | 刷新视频页面，重新播放正片，再点下载 |
| 弹窗显示正在合并 | 合并完成后，文件才会交给浏览器下载器 |
| 想换保存目录 | 到浏览器的下载设置修改默认目录 |
| 出现两个同名扩展 | 移除旧版，保留使用固定 ID 的 0.2.13 或更新版本 |

仍有问题时，请提交浏览器版本、插件版本、出错阶段和能公开分享的复现页面。提交前移除 Cookie、会话凭据和临时 CDN 地址。

## 从源码构建

需要 Node.js 20 或更新版本和 npm。

```sh
npm ci
npm test
npm run build
```

在扩展管理页加载生成的 `dist` 目录。浏览器回归测试及站点适配说明见 [贡献指南](CONTRIBUTING.md)。
